Resource Rush: Deadlock Defense

Resource Rush is a fast-paced 2D game where players manage bots competing to collect resources on a grid, while avoiding system deadlocks. The game simulates operating system concepts like mutual exclusion and deadlock detection, featuring dynamic resource ownership graphs and preemption power-ups.

How to Play: Control bots to collect resources. Holding too many resources without releasing can cause deadlocks, leading to a 'SYSTEM HALTED' game over. Use the 'P' key or the PREEMPT button to activate preemption mode and click on a bot to force it to release a resource. Press 'R' to restart.
